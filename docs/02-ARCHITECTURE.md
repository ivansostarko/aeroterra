# 02 — Architecture

## Design principles
- **100% text-based project**: no binary scene/prefab/model files in git. Scenes are generated by `ProjectBootstrap` (Editor), UI is built at runtime by `UIBuilder`, drone models are procedural meshes. Reviews and merges stay clean.
- **Singletons for cross-scene services** (`GameManager`, `InputManager`, `AudioManager`), auto-created by `BootstrapRuntime` before the first scene loads.
- **Settings-driven world**: every option in Settings maps to a live `Apply*` call plus JSON persistence, so changes take effect instantly, including mid-flight.

## Flight model
Class-aware, force-based physics on a Rigidbody (`DroneFlightController`, model picked from `ModelKind`):

**Multirotors** (CargoX8, QuadFpv, RacingQuad, FoldQuad) — angle mode:
- pitch/roll stick commands a target lean angle tracked by a PD attitude controller; releasing the sticks self-levels and brakes to a hover (position-hold style)
- throttle stick commands a climb/descent rate (`MaxAscentRateMs`); hover thrust is computed automatically each tick and tilt-compensated
- yaw is a rate command integrated into a held target heading

**Fixed wings** (StrikeDelta, LoiteringDelta, TwinBoomUcav, FlyingWing, JetSwept, LightUcav) — aircraft:
- W/S trims a persistent engine power setting; thrust along local forward
- lift `L ∝ v²` along local up (weight fully carried at ~50% max speed, capped at 1.5 g); below stall speed (~26% max) control authority fades and the nose drops
- banked turns are coordinated (`ω = g·tan(bank)/v`); wing-leveler + pitch trim when sticks are centered; spawn/reset hand-launches at cruise speed
- parasitic (v²) + induced drag; Space = airbrake

**VTOL hybrid** (QuadPlane — the Osprey): flies the multirotor model, but a fixed wing progressively carries the weight as forward airspeed builds (fully at ~60% max speed), so the lift rotors wind down in cruise like a real quad-plane transitioning.

**Shared**: Shift = boost (+30% thrust/speed/tilt, ×1.5 battery drain), Space = brake, wind from `WeatherSystem` (Perlin gusts, storm ×4), speed clamp at `MaxSpeedKmh`, hard sea-level floor (altitude never negative), soft ceiling fade at `MaxAltitudeM`, power draw `P = (Cruise + PerThrottle×t) × massRatio × boost` → battery Wh drain; empty battery = no thrust. Kamikaze classes (Vespid/Locust/Wraith — `DroneSpecification.IsKamikazeClass`) detonate the whole airframe on impact and respawn; civilian crashes (cargo, racing, survey, VTOL logistics, camera quad — `!IsMilitaryClass`) are explosion-free (dust + thud).

## Data & persistence
- `DroneSpecification` — ScriptableObject per drone (identity, airframe, performance, battery/payload options, audio profile, default livery)
- `CustomDroneData` — JSON-serializable workshop result (base spec id, battery, payload, colors)
- `SettingsData` — all settings incl. key-binding overrides
- Stored in `Application.persistentDataPath` (`settings.json`, `custom_drones.json`) — works identically on all five platforms.

## Input
Runtime-built Input System actions (Throttle, Pitch, Roll, Yaw, Pause, Camera, Reset, PayloadDrop, Boost, Brake) with keyboard + gamepad bindings; scheme layer adds mouse deltas (KB+M) or device gyro (mobile). Interactive rebinding persists override paths to settings.

## Audio
Per-drone `EngineLoop` clip slot; if empty, a **procedurally synthesized rotor hum** unique to the drone id (fundamental + harmonics + blade-pass frequency + noise) guarantees each drone sounds different out of the box. Pitch/volume track throttle; 3D spatialized with doppler.
