# AeroTerra — True-Earth Drone Flight Simulator

**Unity 3D drone flight simulator on real-world maps** powered by **Cesium for Unity** (photorealistic 3D Tiles, world terrain, OSM buildings) with **OpenStreetMap / OpenFreeMap** raster styles.

Targets: **Windows · Linux · macOS · iOS · Android · WebGL (experimental)**

![AeroTerra](docs/img/banner.png)

---

## Feature overview

| Area | Features |
|---|---|
| **Free Flight** | Map selection (**London**, **Dubai**), drone selection with full specifications, unrestricted flight on real 3D geography |
| **Workshop** | Two hero drones — **AT-C1 "Pelican" cargo delivery drone** and **AT-K2 "Vespid" military kamikaze (loitering munition) drone** — procedurally generated high-detail 3D models; configurable **battery** and **payload**; full **color customization**; save as **custom drone** (JSON persistence) |
| **Settings → Audio** | Master volume (AudioMixer, dB-mapped slider, persisted) |
| **Settings → Controls** | Control schemes: **Keyboard**, **Keyboard + Mouse**, **Gamepad**, **Gyroscope** (mobile). In-game logic for all four. Per-scheme "how to play" graphic + full **key rebinding** for every action (Unity Input System) |
| **Settings → Map** | Map style: **Liberty** (OpenFreeMap), **Terrain**, **Satellite**, **OSM Standard**, **Dark**; toggle **3D Buildings** (Cesium OSM Buildings); toggle **3D Terrain** (Cesium World Terrain) |
| **Settings → Display** | Sky: **Day / Dawn / Dusk / Night** (dynamic sun + gradient ambient). Weather: **Clear / Cloudy / Rain / Storm / Fog / Snow** (particles, fog, lightning, wind affecting flight physics) |
| **Audio** | Distinct engine sound profile per drone (per-drone AudioClip + RPM-driven pitch/volume curves) |
| **Physics** | Quadcopter-style flight model: thrust, pitch/roll/yaw torque, drag, wind, battery drain scaled by throttle & payload mass |

## Quick start (Ubuntu)

```bash
./scripts/setup-ubuntu.sh          # installs Unity Hub + editor + deps
# Open project in Unity Hub (Unity 2022.3 LTS or Unity 6 LTS)
# Menu: AeroTerra ▸ Bootstrap Project   ← generates scenes, prefabs, spec assets
# Set your Cesium ion token: Cesium ▸ Cesium ion Assets (see docs/04-CESIUM-SETUP.md)
# Press Play
```

Full instructions: [`docs/01-DEVELOPMENT-SETUP-UBUNTU.md`](docs/01-DEVELOPMENT-SETUP-UBUNTU.md)

## Building for all platforms

```bash
./scripts/build-all.sh          # everything: Windows / Linux / macOS / Android / WebGL
./scripts/build-windows.sh      # Windows only, cross-built from Ubuntu
./scripts/build-web.sh          # WebGL only (see Cesium/WebGL caveat inside the script)
```
On native Windows: `scripts\build-windows.ps1` (PowerShell) — see [`docs/07-WINDOWS-SETUP.md`](docs/07-WINDOWS-SETUP.md) for what to install first, both to just run a build and to develop on Windows directly.

iOS requires a final Xcode pass on macOS — see [`docs/03-BUILD-GUIDE.md`](docs/03-BUILD-GUIDE.md).

## Working with an AI coding assistant

[`CLAUDE.md`](CLAUDE.md) at the repo root briefs Claude Code (or any AI assistant) on this project's text-based architecture, key entry points, and conventions — read it first before generating code here. `.claude/settings.json` and `.claude/commands/` (project-level, checked into git) provide pre-approved build commands and a few slash commands (`/build-linux`, `/build-windows`, `/build-web`, `/add-city`).
